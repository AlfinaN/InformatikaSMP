Shortcut Keyboard (Tombol Pintas)

  • Ctrl + A : Memilih semua huruf (Select All)
  • Ctrl + B : Menebalkan huruf (Bold)
  • Ctrl + C : Menyalin tulisan (Copy)
  • Ctrl + F : Mencari kata (Find)
  • Ctrl + I : Membuat cetak miring (Italic)
  • Ctrl + S : Menyimpan dokumen (Save)
  • Ctrl + U : Membuat garis bawah (Underline)
  • Ctrl + Z : Membatalkan perintah (Undo)
  • Ctrl + Y : Mengembalikan yang dibatalkan (Redo)
  • Enter : Baris baru / paragraf baru
  • Caps Lock : Mengunci huruf kapital
  • Shift + [Tombol] : Memunculkan simbol khusus
  • Tombol Panah : Navigasi menggeser kursor

Antarmuka UI Word (Ribbon)

  • Rata Kiri, Tengah, Kanan, Penuh : Mengatur posisi teks
  • Insert -> Pictures : Memasukkan gambar
  • Font : Mengganti jenis huruf (Arial, dll)
  • Ukuran Font : Mengganti angka ukuran teks
  • Logo A (Bergaris warna) : Mengubah warna tulisan
